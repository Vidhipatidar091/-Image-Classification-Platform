# AI-Powered Image Classification Platform

**Submitted by:** Vidhi Patidar

## About the Project
This project is an AI-powered image classification platform built using Python and deep learning. It includes a CNN model, a MobileNet model, an API, and a Streamlit frontend.

## Features
- Image classification using deep learning models
- CNN and MobileNet model files
- Python API for predictions
- Streamlit frontend

## Project Structure
- `api.py` — API implementation
- `frontend.py` — User interface
- `main.py` — Main application code
- `pyproject.toml` — Project configuration
- `uv.lock` — Dependency lock file
- `models/` — Saved model files

## Models
- CNN
- MobileNet

## Installation
1. Clone this repository.
2. Install the dependencies listed in `pyproject.toml`.
3. Check that the model files are inside the `models/` folder.
4. Run the application using the commands configured in the project.

## Run the Frontend
```bash
python -m streamlit run frontend.py
